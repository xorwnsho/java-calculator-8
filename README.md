# java-calculator-precourse

## 기능 구현
1. 쉼표(`,`) 또는 클론(`:`)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리하여 각 숫자의 합을 반환한다.  
    (예 : `"1,2:3"` -> 6)  / 다만 빈 문자열 또는 `null` 값을 입력할 경우 0을 반환한다.
2. 숫자 하나만 문자열로 입력할 경우 해당 숫자를 반환한다. (예 : `"5"` -> 5)  
3. `//` 와 `\n` 문자 사이에 커스텀 구분자를 지정할 수 있다. (예 : `"//;\n1;2;3"` -> 6)  
4. 문자열 계산기에 음수를 전달하는 경우 `IllegalArgumentException` 예외를 발생시킨다.  
5. 구분자 외에 다른 문자(숫자가 아닌 값)가 포함된 경우 `IllegalArgumentException` 예외를 발생시킨다.
